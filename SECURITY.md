# 🔒 Política de Seguridad

## Reporte de Vulnerabilidades

Si descubres alguna vulnerabilidad de seguridad en este proyecto, por favor repórtala enviando un correo a `ziko.7xayrn7@proton.me`.

## Buenas Prácticas de Seguridad

1. **Variables de Entorno**: Nunca subas archivos `.env` a repositorios públicos.
2. **Tokens y Secretos**: Utiliza las utilidades incluidas (`npm run spotify-setup`) para gestionar credenciales localmente.
3. **Verificación de Seguridad**: Corre `npm run security-check` antes de realizar despliegues.
