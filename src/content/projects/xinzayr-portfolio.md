# Portfolio Personal - xinzayr

## 📋 Descripción del Proyecto

Este es mi portfolio personal desarrollado con **Astro**, un framework moderno para sitios web estáticos. El proyecto está diseñado para mostrar mis habilidades, proyectos y trayectoria como desarrollador, con un enfoque en la performance y la experiencia de usuario.

## 🎯 Objetivos

- Crear una presencia profesional en línea
- Mostrar proyectos y habilidades técnicas
- Implementar mejores prácticas de desarrollo web
- Optimizar para SEO y performance
- Diseño responsive y accesible

## 🚀 Tecnologías Utilizadas

### Frontend
- **Astro**: Framework principal para generación estática
- **TypeScript**: Tipado estático para mayor robustez
- **TailwindCSS**: Framework de utilidades CSS
- **CSS Grid/Flexbox**: Layout responsive

### Funcionalidades
- **GitHub API Integration**: Datos dinámicos de repositorios
- **Componentes reutilizables**: Arquitectura modular
- **SEO optimizado**: Meta tags y sitemap automático
- **PWA ready**: Service workers y manifest

## 🛠️ Características Principales

### Sistema de Proyectos Dinámico
- Integración automática con GitHub API
- Cards de repositorios con estado de documentación
- Enlaces duales (repositorio + documentación)
- Indicadores visuales de estado

### Secciones Principales
- **About**: Información personal, skills y roadmap
- **Projects**: Visor dinámico de repositorios
- **Blog**: Sistema de contenido con MDX
- **Contact**: Formulario de contacto funcional

### Optimizaciones
- **Lazy loading** de imágenes
- **Code splitting** automático
- **Compresión** de assets
- **Cache** strategies implementadas

## 📱 Diseño Responsive

El sitio está optimizado para funcionar perfectamente en:
- 📱 **Mobile**: 320px - 768px
- 📱 **Tablet**: 768px - 1024px
- 💻 **Desktop**: 1024px+

## 🔧 Instalación y Desarrollo

```bash
# Clonar el repositorio
git clone https://github.com/xinzayr/xinzayr.git

# Instalar dependencias
npm install

# Desarrollo local
npm run dev

# Build para producción
npm run build
```
