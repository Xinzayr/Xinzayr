# Portfolio Personal Interactivo

Este proyecto representa mi presencia digital profesional, desarrollado con las tecnologías más modernas para ofrecer una experiencia única y memorable.

## Características principales

- **Tema negro puro**: Diseño elegante y profesional con efectos acrílicos
- **Totalmente responsive**: Optimizado para todos los dispositivos
- **Hosting dual**: Versión estática en GitHub Pages y dinámica en Vercel
- **Performance optimizada**: Carga rápida y SEO friendly
- **Accesibilidad**: Cumple con estándares WCAG

## Tecnologías utilizadas

### Frontend
- **Astro**: Framework moderno para sitios estáticos
- **TypeScript**: Tipado estático para mayor robustez
- **TailwindCSS**: Diseño utility-first
- **MDX**: Contenido dinámico con componentes

### Hosting e Infraestructura
- **GitHub Pages**: Versión estática
- **Vercel**: Versión dinámica con funcionalidades serverless
- **Cloudflare R2**: Almacenamiento de archivos
- **Firebase**: Base de datos en tiempo real

## Funcionalidades

### Gestión de contenido
- Sistema de blog con MDX
- Portfolio de proyectos dinámico
- Herramientas interactivas
- Formulario de contacto

### Experiencia de usuario
- Animaciones suaves y naturales
- Efectos de cristal (glass morphism)
- Navegación intuitiva
- Modo de carga diferida

### Integración externa
- GitHub para código fuente
- Google Sheets para datos estructurados
- Firebase para funcionalidades dinámicas
- APIs de terceros para contenido

El proyecto demuestra mi capacidad para crear aplicaciones web modernas, escalables y mantenibles usando las mejores prácticas de la industria.
