# Portfolio Personal Interactivo

Un portafolio personal completo y moderno que muestra mis habilidades, proyectos y experiencia como desarrollador full stack.

## Características Principales

- **Diseño Glass Morphism**: Efectos de vidrio y transparencias para un look moderno
- **Tema Negro Puro**: Diseño elegante y profesional
- **Totalmente Responsive**: Optimizado para todos los dispositivos
- **Blog Integrado**: Sistema de blog con soporte para MDX
- **Gestión de Proyectos**: Showcase de proyectos con filtros y categorías
- **Herramientas Útiles**: Sección de herramientas para desarrolladores
- **Formulario de Contacto**: Integración con Formspree para contacto directo

## Tecnologías Utilizadas

- **Astro 5.12.7**: Framework principal para SSG
- **TypeScript**: Tipado estático para mayor robustez
- **TailwindCSS**: Estilos utility-first con configuración personalizada
- **MDX**: Contenido dinámico en Markdown con componentes React
- **React**: Componentes interactivos cuando es necesario

## Arquitectura del Proyecto

El proyecto está estructurado para facilitar el mantenimiento y la escalabilidad:

```
src/
├── components/     # Componentes reutilizables
├── layouts/        # Layouts base para páginas
├── pages/          # Páginas del sitio
├── content/        # Contenido en MDX (blog, proyectos, herramientas)
├── utils/          # Utilidades y helpers
└── styles/         # Estilos globales
```

## Optimizaciones

- **Rendimiento**: Carga rápida con SSG y optimización de imágenes
- **SEO**: Meta tags optimizados y sitemap automático
- **Accesibilidad**: Diseño accesible con navegación por teclado
- **Hosting Dual**: Compatible con GitHub Pages (estático) y Vercel (dinámico)

Este proyecto representa mi enfoque actual hacia el desarrollo web moderno, combinando las mejores prácticas con un diseño atractivo y funcional.
