# Generador de URLs Cortas

Una herramienta sencilla y eficaz para acortar URLs largas y obtener estadísticas de uso.

## Características

- Acortamiento rápido de URLs
- Enlaces personalizables
- Estadísticas de clics en tiempo real
- Código QR automático
- API REST disponible

## Cómo usar

1. Pega tu URL larga en el campo de entrada
2. Opcionalmente, personaliza el código corto
3. Genera tu enlace corto
4. Comparte y sigue las estadísticas

Esta herramienta es perfecta para redes sociales, campañas de marketing y compartir enlaces de forma más limpia.
